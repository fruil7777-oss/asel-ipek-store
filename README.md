# Asel Ipek - متجر الحجابات الفاخرة

## 🎯 نبذة عن المشروع

متجر إلكتروني احترافي متكامل متخصص في بيع الحجابات الفاخرة والأنيقة بأعلى جودة عالمية.

## 🛠️ التقنيات المستخدمة

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Database**: Firebase Firestore
- **Storage**: Firebase Storage
- **State Management**: Zustand
- **Multilingual**: Support for Arabic, English, Turkish

## 🚀 البدء السريع

### التثبيت

```bash
npm install
```

### المتغيرات البيئية

أنشئ ملف `.env.local` بالمتغيرات المطلوبة

### التشغيل

```bash
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)
